BOOTSTRAP
Dedicated F13PostAuthAttach.exe launched automatically by a command shortcut.
It launches the existing game, recognizes its exact normal process/path, waits
until Offline Play is current, loads the backend once, verifies module presence
and then stops polling. No dependency on Windows resolving a local proxy DLL;
no renamed/modified EXEs, no registry/security changes or System32 writes.
Import inspection confirmed game VERSION/WINMM imports, but no new proxy was
chosen: existing OnlineFix winmm/loader files remain untouched. Windows APIs
provide bootstrap loading, so there is no original-export forwarding contract.
This is a stronger packaging design, NOT a guarantee against access denial,
anti-cheat, antivirus quarantine, incompatible EXEs or untested Windows setups.

BACKUPS / UNINSTALL
Every existing same-name target is backed up before any overwrite. Upgrade
retains the original baseline and journals immediate rollback files separately.
Uninstall removes only manifest-owned installed targets, restores originals,
and refuses unexpected changes. It never removes game content/saves. Backup
history and extracted documentation/setup files remain recoverable.
The real new F-drive install had no previous backend/launcher files to replace.
The original game EXE and OnlineFix DLL were hash-checked unchanged after the
real install/uninstall/reinstall test; existing loader bytes were preserved.
